# بوت تسجيل الدخول/الخروج + البث الخاص

## المميزات
- أمر `/broadcast` يرسل رسالة خاصة (DM) لكل الأعضاء الذين يملكون رتبة معينة.
- أمر `/setup-panel` يرسل لوحة (زرّين: تسجيل دخول / تسجيل خروج) إلى روم تحدده — وله نوعين منفصلين: **الإدارة** و**الرقابة**، كل وحدة برومها الخاص.
- عند الضغط على **تسجيل خروج** فقط (مو تسجيل دخول) تنولّد صورة بخلفية بنفسجية فيها اسم الشخص ومدة بقائه مسجل دخول، وترسل تلقائيًا لروم السجل.
- ما يقدر أحد يسجل **خروج** إلا إذا كان مسجل **دخول** فعليًا (وإلا يوصله رد خاص فيه تنبيه).
- ما يقدر يسجل دخول مرتين متتاليتين بدون تسجيل خروج بينهم.

## خطوات التثبيت

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```

2. **إعداد بيانات البوت:**
   - انسخ ملف `.env.example` باسم `.env`.
   - عبّي `DISCORD_TOKEN` (من بوابة مطوري ديسكورد → Bot → Token).
   - عبّي `CLIENT_ID` (Application ID من صفحة General Information).
   - عبّي `GUILD_ID` (معرف السيرفر - فعّل Developer Mode وانسخه بالزر اليمين على السيرفر).

3. **تفعيل الصلاحيات (Intents) في بوابة المطورين:**
   من صفحة تطبيقك في https://discord.com/developers/applications → Bot، فعّل:
   - `SERVER MEMBERS INTENT` (ضروري لأمر البث ولمعرفة أسماء الأعضاء).

4. **دعوة البوت للسيرفر** بصلاحيات:
   - Send Messages, Embed Links, Attach Files, Use Application Commands.

5. **تسجيل الأوامر:**
   ```bash
   npm run deploy
   ```

6. **تشغيل البوت:**
   ```bash
   npm start
   ```

## طريقة الاستخدام داخل ديسكورد

1. أرسل الأمر:
   ```
   /setup-panel النوع:الإدارة روم_اللوحة:#room-admin روم_السجل:#logs-admin
   ```
   وكرره لنوع الرقابة:
   ```
   /setup-panel النوع:الرقابة روم_اللوحة:#room-oversight روم_السجل:#logs-oversight
   ```
   (روم_السجل اختياري؛ إذا ما حددته، الصور ترسل بنفس روم اللوحة).

2. لإرسال رسالة خاصة لكل أعضاء رتبة معينة:
   ```
   /broadcast الرتبة:@السيارة الرسالة:نص رسالتك هنا
   ```

## ملاحظة عن الخط العربي في الصورة
الصورة تُرسم بمكتبة `@napi-rs/canvas`. لضمان ظهور الحروف العربية متصلة وبشكل صحيح، حمّل خط عربي (مثل **Cairo** أو **Tajawal** أو **Dubai**) بصيغة `.ttf`، وسمّه `arabic.ttf`، وحطه داخل مجلد `fonts/`. البوت يكتشفه ويستخدمه تلقائيًا. إذا ما حطيت خط، بيستخدم خط النظام الافتراضي وقد لا تظهر الحروف العربية متصلة بشكل مثالي.

## هيكل الملفات
```
duty-bot/
├── index.js              # الملف الرئيسي وتشغيل البوت
├── deploy-commands.js    # تسجيل أوامر السلاش
├── commands/
│   ├── setup-panel.js    # أمر إرسال اللوحة
│   └── broadcast.js      # أمر البث الخاص
├── utils/
│   ├── panels.js         # إدارة إعدادات اللوحات (قنوات اللوحة/السجل)
│   ├── sessions.js       # إدارة جلسات الدخول/الخروج النشطة
│   ├── image.js          # توليد صورة السجل البنفسجية
│   ├── formatDuration.js # تحويل المدة لنص عربي مقروء
│   └── storage.js        # قراءة/كتابة ملفات JSON
├── config/panels.json    # بيانات اللوحات (تلقائي)
├── data/sessions.json    # الجلسات النشطة (تلقائي)
└── fonts/                # ضع هنا خط عربي arabic.ttf (اختياري لكن يفضل)
```

## تخصيصات سهلة
- لتغيير لون اللوحات أو التسمية: عدّل `config/panels.json`.
- لتغيير تصميم صورة السجل (الأحجام/الألوان): عدّل `utils/image.js`.
- البيانات تُخزَّن بملفات JSON بسيطة، فإذا أعدت تشغيل البوت تبقى الجلسات النشطة محفوظة.
